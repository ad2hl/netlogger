# AD2HL Net Logger — Help

AD2HL Net Logger is an amateur radio net logging application for net control operators.

## Getting Started

1. **Create a new net session** — Start a new session for your net. Enter the net name, date, and start time.
2. **Log check-ins** — As stations check in, type their callsign (with optional tags like `/T`, `/A`, `/NC`) and press Enter.
3. **Manage traffic** — Use the checklist to track traffic items and announcements.
4. **Create radiograms** — Use the Radiograms section to create and print ARRL-format radiograms.
5. **End the session** — Enter an end time in the Session Summary panel when the net closes.

## Pages

- **Sessions** — View and manage all past and current net sessions.
- **Radiograms** — Browse radiograms across all sessions.
- **Manage users** — View and edit station memory (callsigns, names, locations, notes).
- **Settings** — Configure your callsign, profile, QRZ credentials, and disposition methods.

## Check-In Tags

| Tag | Meaning |
|-----|---------|
| `/NC` | Net Control |
| `/ANC` | Alternate Net Control |
| `/T` | Traffic |
| `/A` | Announcement |
| `/S` | Secure |
| `/IO` | In-and-out |
| `/M` | Mobile |
| `/P` | Portable |
| `/OC`, `/HVN`, etc. | Liaison nets |

## Tips

- Press `?` before a callsign in the check-in field to search existing stations.
- The net report generates an ARRL-format radiogram with callsign compression.
- Radiograms can be printed to PDF using the Print button.
