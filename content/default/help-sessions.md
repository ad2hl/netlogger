# Sessions Help

## Overview

The Sessions page lists all your net sessions. Click any row to open that session in the net logging view.

## Creating a New Session

Click **New Session** to open the session creation form. Enter:

- **Net Name** — the name of the net (e.g., SDN). Pre-filled from the most recent session.
- **Date** — defaults to today.
- **Start Time** — the scheduled or actual start time.

If a session is currently active (no end time), you will be prompted before a new one is created. Proceeding will automatically record an end time for the active session.

## Session Table

The table is sortable by any column — click a column header to sort, click again to reverse. Columns include:

- **Date / Start / End** — session timing
- **Net Name** — the net identifier
- **NCS / ANCS** — callsigns of the Net Control and Alternate Net Control stations
- **Stations** — number of check-ins
- **Rptd / Clrd** — traffic reported and cleared counts
- **Duration** — time between start and end (or elapsed time for active sessions)

## Deleting a Session

Click the trash icon on the right side of a session row to permanently delete it, including all check-ins, radiograms, and reports.
